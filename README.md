# Sistema de Gerenciamento de Biblioteca

Sistema desenvolvido em Java como projeto acadêmico, com o objetivo de gerenciar as operações de uma biblioteca. 
O projeto aplica os conceitos de Programação Orientada a Objetos (POO) e realiza a integração com um banco de dados PostgreSQL utilizando JDBC.

## Tecnologias

- Java
- JDBC
- PostgreSQL
- Maven

## Conceitos Aplicados

- Programação Orientada a Objetos (POO)
- Herança
- Polimorfismo
- Encapsulamento
- Associações entre classes
- Padrão DAO (Data Access Object)
- Separação em camadas

## Objetivo

Este projeto foi desenvolvido como atividade acadêmica para consolidar conhecimentos em Java, modelagem orientada a objetos, acesso a banco de dados e organização de aplicações em camadas.
